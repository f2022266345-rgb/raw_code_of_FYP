Lumina Runtime Flow (Chat)

1) Frontend sends message to Express: POST /api/chat
2) Express authenticates, fetches recent InteractionLog turns, and forwards message + chatHistory + database_chat_history to FastAPI: POST /api/agent/chat
3) FastAPI retrieves student context (InitialProfile, BKT, InteractionLog, AgentMemory)
4) If agent_type is coordinator/auto/router, FastAPI runs lightweight routing and sets routed_agent
5) FastAPI applies agent guardrails (Academic handoff for wellness topics) and builds state/persona prompt
6) FastAPI builds a context window and AI summary of chat history, then calls the model
7) FastAPI returns response + state/persona + routed_agent
8) Express logs the conversation and returns response to frontend
9) FastAPI runs background extraction to update InitialProfile fields:
   - learning_barriers_score
   - wellness_support_needed
   - social_support_needed

Shared Memory
- Agents read from InitialProfile + BKT + AgentMemory
- Agents write updates into InitialProfile via background extraction
