Week 8: BKT Model & Trend Detection Implementation
Tasks:

Code
8.1 Implement BKT Model (Bayesian Knowledge Tracing)
    ├─ Define BKT parameters:
    │  ├─ P(Init) = 0.15 (started knowing)
    │  ├─ P(Transit) = 0.4 (learn from exercise)
    │  ├─ P(Slip) = 0.08 (know but answer wrong)
    │  └─ P(Guess) = 0.2 (don't know but guess right)
    │
    ├─ Update formula after each response:
    │  IF correct:
    │    L_new = (1-P(S)) * L_old + (1-P(S)) * (1-L_old) * P(T)
    │  ELSE:
    │    L_new = L_old (no learning)
    │
    ├─ Store h_mastery in database after each exercise
    └─ Test: Track mastery progression over 5 exercises

8.2 Implement Linear Regression Trend Detection
    ├─ Query last 5-7 interactions
    ├─ Extract features:
    │  ├─ Accuracy trend (is accuracy improving?)
    │  ├─ Response time trend (are they getting faster?)
    │  └─ Help-seeking trend (asking for more hints?)
    │
    ├─ Run linear regression: y = mx + b
    ├─ Calculate:
    │  ├─ h_trend (slope direction)
    │  ├─ h_momentum (slope magnitude)
    │  └─ h_frustration (combining signals)
    │
    └─ Test: Trend detection on test student

8.3 Create Hidden State Calculation Service
