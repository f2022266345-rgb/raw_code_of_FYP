LUMINA: Culturally-Aware Agentic AI Ecosystem
Project Documentation & Progress Report
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Lumina is an advanced, multi-agent AI tutoring ecosystem designed specifically 
for university students in Pakistan (e.g., UMT Lahore). It moves beyond standard 
chatbots by utilizing Bayesian Knowledge Tracing (BKT), cognitive trend analysis, 
and culturally-aware prompt engineering to provide personalized academic and 
wellness support.

Target Prototype Completion: 2 Months
Primary End-User: Pakistani University Students

2. SYSTEM ARCHITECTURE
--------------------------------------------------------------------------------
The system is divided into three core layers:

LAYER 1: Data Collection & Initial Profile
* 4-Step Onboarding Form: Collects educational background, VARK learning 
  preferences, cultural context, and a diagnostic quiz score.
* Initial Prediction Model: A trained Random Forest Classifier evaluates the 
  onboarding data to predict the student's success risk (0 for High Risk, 1 for 
  On Track).
* Outputs: Establishes the initial Bloom's Taxonomy level, identifies language 
  barrier risks, and determines which sub-agents to activate.

LAYER 2: Storage & Continuous Observations
* Database: PostgreSQL (with pgvector for semantic AI memory).
* Observable Parameters Logged: 
  - Academic: Correct/Incorrect, Response Time, Hints Used, Attempts.
  - Wellness: Self-reported Mood, Sentiment Analysis, Engagement Metrics.

LAYER 3: Models (Inference & Adaptation)
The "Brain" of the system relies on three distinct models working in tandem:

  Model A: Bayesian Knowledge Tracing (BKT)
  - Purpose: Tracks the student's exact mastery of specific topics.
  - Hidden State: P(Know) [Probability the student understands the skill].
  - Status: Trained via pyBKT on the ASSISTments dataset. Parameters extracted 
    to CSV for O(1) backend lookups.

  Model B: Cognitive Trend Detection
  - Purpose: Real-time heuristic algorithm identifying emotional/performance 
    trajectories using linear regression (NumPy slope calculations).
  - Hidden State: Trend classification (e.g., CRITICAL_STRUGGLE, FLOW_STATE, 
    DISENGAGED).
  - Triggers: Detects patterns such as "Frustration ↑ + Performance ↓".

  Model C: LLM Generative Engine (Gemini 1.5 Flash / Gemma 2B)
  - Purpose: The "Voice" of the agents.
  - Mechanism: Uses dynamic system prompting. The backend injects the P(Know) 
    and Trend states to dictate the LLM's pedagogy, tone, and cultural analogies 
    (e.g., using Roman Urdu or local UMT campus references).

3. THE AGENTIC ECOSYSTEM
--------------------------------------------------------------------------------
Lumina operates using a localized swarm architecture:

* The Coordinator Agent: The orchestrator. It reads the database, updates the 
  BKT and Trend hidden states, and routes the student to the appropriate sub-agent.
* The Academic Agent: Focuses on Bloom's Taxonomy-aligned tutoring. Uses the 
  Socratic method for struggling students and fast, peer-to-peer answers for 
  high-mastery students.
* The Wellness Agent: Focuses on emotional support, intervening when 
  CRITICAL_STRUGGLE or high frustration is detected.
* The Social Agent: Focuses on peer-like engagement and cultural connection.
